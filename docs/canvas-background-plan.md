# 画布默认背景移植计划

把 tldraw 参考项目的静态渐变用作 ComfyArt 的默认画布背景。新建项目和从未选过背景色的旧项目随主题显示渐变，已经选过背景色的项目继续显示保存的颜色。开花动效留待以后讨论。

## 配色

参考项目的 `local-agent/client/index.css` 定义了以下两套背景。浅色模式从上方淡蓝过渡到底部淡粉，左上和右侧各叠一层柔和的局部颜色。深色模式从上到下逐渐加深。

```css
/* 浅色 */
background:
  radial-gradient(ellipse at 92% 72%, rgb(248 212 233 / 48%), transparent 58%),
  radial-gradient(ellipse at 15% 5%, rgb(224 244 255 / 42%), transparent 58%),
  linear-gradient(180deg, #b2d1eb 0%, #d5e5f3 42%, #eef0f9 72%, #fae8ef 100%);

/* 深色 */
background: linear-gradient(180deg, #19364e, #111e2d);
```

## 实现顺序

1. 在 `src/styles/base.css` 给画布背景层设置上述主题渐变。让渐变铺满可视区域，拖动和缩放时只移动作品。整个背景用 CSS 绘制。
2. 调整 `src/ui/CanvasTools.tsx`。目前它在文档没有背景色时也会写入默认灰色，覆盖样式表。改为只在文档保存了自选颜色（`meta.bg`）时覆盖渐变。仅打开项目或切换主题时，无需改写文档。
3. 让画布选色按钮能显示当前渐变或纯色。默认状态标为“跟随主题”，手动选色继续使用现有十六进制输入。在画布选色面板提供恢复默认的入口，只清除背景色字段。

## 验收

- 打开新项目和未设底色的旧项目，分别体验浅色、深色和跟随系统。对照参考画布检查渐变方向、色带位置，并确认全程静止。
- 在已有自选颜色的项目中切换主题、保存并重新打开，确认画布和按钮仍显示保存的颜色。恢复默认后刷新，确认重新跟随主题。
- 平移、缩放、打开侧栏，检查画布边缘和空白区域有无接缝。导出同一作品，对照改动前的输出，确认编辑器渐变没有进入作品。
- 实现后运行 `npm run build`，在 PR 附上同一画面的浅色和深色截图。
